# Proof Guide

**Audience:** public reviewer / independent evaluator  
**Document type:** evidence guide

## Visible proof path

| Step | Expected state | Evidence to inspect |
|---|---|---|
| Confirm signed agreement | COMPLETE | owner + signed agreement reference |
| Schedule kickoff | COMPLETE | predecessor satisfied + calendar confirmation |
| Collect access requirements | BLOCKED | active blocker: client has not named system admin |
| Prepare initial workspace | WAITING | required predecessor remains incomplete |
| Confirm training handoff | WAITING | migration predecessor remains incomplete |

## Export proof

Use **Export visible CSV**. The exported representation should preserve the visible evaluated status and reason rather than silently changing the workflow state.
