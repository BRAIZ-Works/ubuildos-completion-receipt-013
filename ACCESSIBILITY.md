# Accessibility

**Audience:** public users / accessibility reviewer  
**Document type:** accessibility statement

The live public interface uses semantic headings, labels, a keyboard-accessible skip link, visible focus styling, status text in addition to color, native select/button controls, responsive layouts, and readable text wrapping.

Live visual review was performed on desktop, narrower/tablet, and mobile presentations supplied during Day 12.

## Limitation

This statement does not claim formal WCAG conformance certification. The LinkedIn carousel is accompanied by a text/reading-order companion because the PDF is not represented as a fully tagged accessible PDF.
