## Purpose
Turn a signed-client handoff into an inspectable checklist of required steps, accountable owners, dependencies, blockers, completion evidence, and export.

## What to inspect
1. A required step cannot complete without required evidence.
2. An incomplete predecessor keeps downstream work waiting.
3. An active blocker remains visible.
4. A missing owner or contradictory evidence routes to REVIEW.
5. CSV export preserves the visible status, reason, dependencies, blocker, and evidence.

## Run locally
Serve this directory with any static HTTP server and open `index.html`. The demo uses synthetic records only and performs no external writes.

## Public boundary
This is a workflow demonstration. It does not claim faster onboarding, higher retention, revenue impact, CRM integration, regulated-data readiness, or replacement of human judgment.
